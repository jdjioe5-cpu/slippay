# x402 Protocol API (`/v1/x402-resources` & `/v1/x402`)

The x402 module implements the open HTTP 402 (Payment Required) standard for content and resource gating using Stellar USDC micropayments.

---

## Protocol Lifecycle

```
Client (Browser/Agent)                 SlipPay Gateway                      Stellar Ledger
       │                                     │                                    │
       ├──── 1. GET /v1/x402/:slug ─────────►│                                    │
       │                                     │                                    │
       │◄─── 2. 402 Payment Required ────────┤                                    │
       │    (asset, amount, memo, pay-to)    │                                    │
       │                                     │                                    │
       ├──── 3. Submit USDC Payment ─────────┼───────────────────────────────────►│
       │    (signed with assigned memo)      │                                    │
       │                                     │◄── 4. SlipPay Matcher Listener ────┤
       │                                     │    (detects order paid on-chain)   │
       ├──── 5. Retry GET /v1/x402/:slug ────►│                                    │
       │                                     │                                    │
       │◄─── 6. 200 OK (Gated Content) ──────┤                                    │
```

1. **Registration**: A merchant registers a protected asset or API endpoint with an attached USDC price.
2. **Challenge (402)**: When an unauthenticated client requests `/v1/x402/:slug`, SlipPay issues a pending order and returns HTTP status `402 Payment Required` containing structured Coinbase x402-compatible settlement requirements.
3. **Settlement**: The buyer submits a standard on-chain payment with the issued memo.
4. **Access Grant**: On subsequent GET requests from the same client identity, SlipPay verifies the order transition to `paid` and serves the gated resource payload.

---

## Endpoints

### 1. `POST /api/v1/x402-resources` (Merchant Auth: `Bearer sk_live_...`)
Registers a new resource to be gated behind x402 micropayments.

**Request Body:**
```json
{
  "slug": "premium-market-report",
  "name": "Q3 Macro Intelligence Report",
  "price_usdc": "1.50",
  "content": "Secret report body or presigned content download URL",
  "content_type": "text/markdown"
}
```

**Response (201 Created):**
```json
{
  "id": "res_876a5b4c",
  "slug": "premium-market-report",
  "price_usdc": "1.5000000",
  "url": "https://api.slippay.cc/api/v1/x402/premium-market-report"
}
```

---

### 2. `GET /api/v1/x402-resources` (Merchant Auth: `Bearer sk_live_...`)
Lists all gated resources registered by the authenticated merchant.

**Response (200 OK):**
```json
{
  "resources": [
    {
      "id": "res_876a5b4c",
      "slug": "premium-market-report",
      "price_usdc": "1.5000000",
      "orders_count": 42
    }
  ]
}
```

---

### 3. `GET /api/v1/x402/:slug` (Public)
Fetches the gated resource.

**Unpaid Response (402 Payment Required):**
```json
{
  "x402": {
    "version": "1.0",
    "network": "stellar",
    "asset": {
      "code": "USDC",
      "issuer": "GA5Z...IssuerPublicKey"
    },
    "amount": "1.5000000",
    "recipient": "GMRK...MerchantAddress",
    "memo": "402-a1b2c3d4",
    "order_id": "ord_x402_12345",
    "expires_at": "2026-10-20T12:30:00Z"
  }
}
```

**Paid Response (200 OK):**
Serves the registered content (or redirects to the protected target) once the matcher confirms on-chain payment.
